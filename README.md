##   这是什么？

> **QSYS 是一个能够自我进化、自我迭代的全自动量化交易系统**

### 系统简介

**QSYS**（Quantitative System）是一个**全流程自动化**的量化投资系统。它将传统量化研究中分散的因子挖掘、策略构建、回测验证、实盘交易等环节，整合成一个**自我进化、持续学习**的智能系统。

传统量化研究需要研究员花费数周甚至数月的时间去发现一个有效的Alpha因子，然后手动验证、组合、测试。而QSYS通过**遗传算法**和**机器学习**，可以**每天自动生成数百个因子候选**，自动验证其有效性，并自动构建策略组合。

**QSYS 的核心理念是：让机器做机器擅长的事情，让人类专注于决策。**

### 核心特性：三大革命性突破

#### 革命一：全流程自动化

```
传统量化研究                          QSYS 自动化研究
─────────────────────────────────────────────────────────────
人工发现因子  ──▶  人工验证  ──▶  人工组合     自动发现因子  ──▶  自动验证  ──▶  自动组合
     │                │                │             │                │                │
     ▼                ▼                ▼             ▼                ▼                ▼
  几十个因子      几周验证      几个月策略     37,000+因子     实时验证      每日更新策略
     │                │                │             │                │                │
     ▼                ▼                ▼             ▼                ▼                ▼
  手动交易        手动调整        低效复用     自动交易        持续优化      智能进化
```

**传统量化研究**需要人工发现因子、人工验证、人工组合，整个过程耗时数周甚至数月。而**QSYS**实现了全流程自动化，从因子发现到实盘交易，全程无需人工干预。

系统可以**每天自动生成数百个因子候选**，通过严格的IC/ICIR/胜率验证后，自动构建策略组合，并自动执行交易。整个过程**无需人工干预**，系统自主运行。

**自我迭代**是QSYS的核心能力之一。系统每天都会自动生成新的因子，验证其有效性，并根据验证结果更新策略。这个过程是**持续不断的循环**，系统每天都在进化。

具体来说，系统每天会：
1. **生成新因子**：基于遗传算法，自动搜索因子空间
2. **验证有效性**：通过IC、ICIR、胜率等指标严格验证
3. **更新策略**：将有效因子自动构建为策略组合
4. **优化参数**：根据历史表现自动调整策略参数

这个过程**无需人工干预**，系统自主完成。随着运行时间的增长，系统会积累越来越多的经验，变得越来越聪明。

##   核心功能

### 1.   因子演化引擎 (LoopEngine)

**自动发现Alpha因子**：基于遗传算法，自动生成、验证、筛选因子

```python
# 系统自动生成的因子（无需人工编写）
le_影线_5f5871 = sub(
    decay_linear(sub(decay_linear(roc(open,200),200), sign(amount)), 200),
    sign(delta(ts_min(ts_max(lower_shadow,120),20), 200))
)

# 系统每天生成数百个因子候选，自动验证有效性
```

**核心能力**：
- **多类型因子挖掘**：量价、资金流、板块轮动、龙虎榜、盘口异动、指数
- **自适应预算**：根据成功率动态调整算子权重
- **FSA失败模式库**：101,847条失败记录，避免重复尝试
- **硬闸门验证**：IC/ICIR/胜率多重过滤

**工作原理**：
1. **遗传算法搜索**：系统使用遗传算法在因子空间中自动搜索有效的因子表达式
2. **多类型因子挖掘**：支持量价、资金流、板块轮动、龙虎榜、盘口异动、指数等6大类因子
3. **自适应预算**：根据历史成功率动态调整算子权重，优先探索成功率高的方向
4. **FSA失败模式库**：记录所有失败的因子骨架，避免重复尝试相同的失败模式
5. **硬闸门验证**：每个因子必须通过IC>0.02、ICIR>0.2、胜率>50%等多重过滤

### 2.   因子评估系统

**严格的因子验证流程**：

```
因子候选 ──▶ 闸门检查 ──▶ Walk-forward验证 ──▶ 胜率体检 ──▶ 入库评分
    │           │              │              │          │
    │           │              │              │          └── 5维评分
    │           │              │              └── 1/5/20/60/120日多周期
    │           │              └── 样本外真实表现
    │           └── IC > 0.02, IC_winrate > 50%
    └── 去重、骨架分类、机制族归属
```

**5维因子评分**：
- **IC得分 (30%)**: |IC| × IC_winrate，衡量因子预测能力
- **稳定性 (25%)**: IC胜率，衡量因子预测的稳定性
- **一致性 (20%)**: Top组胜率，衡量因子在Top组的表现一致性
- **使用度 (15%)**: 被策略包引用次数，衡量因子的实用价值
- **新鲜度 (10%)**: 最近更新时间，衡量因子的时效性

**验证流程详解**：
1. **闸门检查**：IC>0.02, IC_winrate>50%，ICIR>0.2
2. **Walk-forward验证**：滚动窗口验证，确保样本外表现
3. **胜率体检**：1/5/20/60/120日多周期胜率验证
4. **去重**：基于骨架的去重，避免重复因子
5. **机制族归属**：将因子归类到不同的机制族

### 3.   策略包自动生成

**从因子到策略的自动化流水线**：

```python
# 1. 因子发现：从37,000+因子库中筛选Top因子
# 2. 组合构建：贪心选择 + MMR去冗余
# 3. Walk-forward验证：样本外胜率 ≥ 50%
# 4. 质量门槛：OOS胜率 + 实战差距 < 25%
# 5. 自动入库：保存到strategies表

# 多包投票机制（降低过拟合风险）
pack1_stocks = compute_pack_picks(alpha101, codes)  # Alpha101精华
pack2_stocks = compute_pack_picks(short5, codes)    # 短线5日
pack3_stocks = compute_pack_picks(stable, codes)    # 稳健低波

# 取至少2票的交集
final_stocks = intersection(pack1, pack2, pack3)
```

**策略包生成流程**：
1. **因子筛选**：从37,000+因子库中筛选Top因子（ICIR > 0.2）
2. **组合构建**：使用贪心选择 + MMR去冗余，构建5-8个因子的组合
3. **Walk-forward验证**：滚动窗口验证，确保样本外胜率 ≥ 50%
4. **质量门槛**：OOS胜率与实战差距 < 25%，避免过拟合
5. **自动入库**：保存到strategies表，供选股使用

**多包投票机制**：
- **Top3策略包投票**：Alpha101精华、短线5日、稳健低波等
- **取至少2票的交集**：降低过拟合风险
- **动态权重**：根据实战表现调整各策略包权重

### 4.   自动选股与交易

**完整的交易闭环**：

```
19:00  pool_scan     → 板块扫描选股（多包投票）
19:30  auto_scan     → 自动选股（v5因子评分）
09:26  auction_confirm → 竞价确认
09:30+ position_track → 持仓跟踪（每5分钟）
        │
        ├── 开仓条件：止盈+15% / 止损-8% / 持有20天
        └── 自动执行：无手动确认
```

**v5自动选股算法**：
- **因子价值评分 (25%)**: backtest_winrate, IC均值, IC正率
- **技术信号 (20%)**: 动量、波动率、成交量
- **市场环境 (15%)**: 涨跌比、波动率、成交额
- **风险控制 (20%)**: 最大回撤、夏普比率
- **稳定性 (10%)**: 持仓周期、换手率
- **分散度 (10%)**: 行业数量、个股数量

**交易执行**：
- **竞价确认**：09:26自动确认竞价
- **自动开仓**：符合条件自动开仓
- **持仓跟踪**：每5分钟检查持仓状态
- **止盈止损**：止盈+15% / 止损-8%
- **无手动确认**：全程自动化，无需人工干预

### 5.   经验学习系统

**从历史中学习**：


**实际效果**：

##   因子演化引擎优化方案

### 当前系统分析

| 问题 | 现状 | 影响 |
|------|------|------|
| **因子衰减无检测** | 因子入库后永不退役 | 过期因子持续贡献错误信号 |
| **回测胜率≠实盘胜率** | Walk-forward验证基于历史数据 | OOS 86% → 实战47%，差距39% |
| **无收益风险平衡** | 只关注IC/ICIR，忽略回撤 | 高IC因子可能带来高波动 |
| **多样性不足** | FSA冻结是唯一机制 | 容易陷入局部最优 |
| **算子权重静态** | 字段权重只按频率调整 | 不区分好因子和坏因子的贡献 |

### 优化方案：四大模块

#### 模块一：因子衰减检测系统

**核心思想**：因子的预测能力会随时间衰减，需要实时监控并自动退役。

```
因子衰减检测流程：
─────────────────────────────────────────────────────────────────

  因子IC序列
      │
      ▼
┌─────────────────────────────────────────────────────────┐
│  滑动窗口监控                                            │
│                                                         │
│  近60天IC  vs  历史IC                                   │
│      │              │                                   │
│      ▼              ▼                                   │
│  IC衰减率 = (近60天IC - 历史IC) / |历史IC|              │
│                                                         │
│  衰减阈值：                                              │
│  ├── 轻度衰减: IC衰减率 < -30%  → 降低权重              │
│  ├── 中度衰减: IC衰减率 < -50%  → 标记警告              │
│  └── 重度衰减: IC衰减率 < -70%  → 自动退役              │
│                                                         │
└─────────────────────────────────────────────────────────┘

  实现方式：
  - 新增 factor_decay 表，记录每个因子的衰减状态
  - 每周自动运行衰减检测
  - 衰减因子自动从策略包中移除
```

#### 模块二：实盘胜率优化

**核心思想**：从"回测胜率高"转向"实盘胜率高"，减少过拟合。

```
实盘胜率优化策略：
─────────────────────────────────────────────────────────────────

  当前问题：
  ├── OOS胜率86% → 实战47%（差距39%）
  ├── Walk-forward验证基于历史数据
  └── 无实盘表现反馈机制

  优化方案：
  ┌─────────────────────────────────────────────────────────┐
  │  1. 样本外严格隔离                                      │
  │     - 最近60天数据完全隔离，不参与任何训练              │
  │     - Walk-forward验证窗口后移60天                      │
  │                                                         │
  │  2. 实盘表现反馈                                        │
  │     - 记录每个因子的实盘表现                            │
  │     - 计算实盘胜率 vs 回测胜率的差距                    │
  │     - 差距>25%的因子自动降权                           │
  │                                                         │
  │  3. 多市场验证                                          │
  │     - 在不同市场环境下验证因子                          │
  │     - 牛市/熊市/震荡市分别验证                          │
  │     - 只在多种市场环境下都有效的因子才入库              │
  │                                                         │
  │  4. 因子稳定性评分                                      │
  │     - IC波动率：IC标准差越小越稳定                      │
  │     - IC趋势：IC是否在下降                              │
  │     - IC一致性：不同时间窗口的IC是否一致                │
  └─────────────────────────────────────────────────────────┘
```

#### 模块三：收益风险平衡

**核心思想**：在追求高收益的同时控制最大回撤和波动率。

```
收益风险平衡策略：
─────────────────────────────────────────────────────────────────

  当前问题：
  ├── 只关注IC/ICIR，忽略回撤
  ├── 高IC因子可能带来高波动
  └── 无风险调整后收益指标

  优化方案：
  ┌─────────────────────────────────────────────────────────┐
  │  1. 新增风险指标                                        │
  │     - 最大回撤 (Max Drawdown)                           │
  │     - 夏普比率 (Sharpe Ratio)                           │
  │     - 索提诺比率 (Sortino Ratio)                        │
  │     - 卡玛比率 (Calmar Ratio)                           │
  │                                                         │
  │  2. 多目标评分                                          │
  │     Score = α × IC + β × (1 - MaxDD) + γ × Sharpe      │
  │     其中 α=0.4, β=0.3, γ=0.3                          │
  │                                                         │
  │  3. 风险预算                                            │
  │     - 每个策略包的最大回撤限制: 15%                     │
  │     - 每个行业最大暴露限制: 20%                         │
  │     - 每只股票最大持仓限制: 5%                          │
  │                                                         │
  │  4. 动态止损                                            │
  │     - 基于波动率的动态止损                              │
  │     - ATR止损: 止损线 = 入场价 - 2 × ATR               │
  │     - 时间止损: 持有超过20天自动平仓                    │
  └─────────────────────────────────────────────────────────┘
```

#### 模块四：多样性增强

**核心思想**：防止算法陷入局部最优，保持因子多样性。

```
多样性增强策略：
─────────────────────────────────────────────────────────────────

  当前问题：
  ├── FSA冻结是唯一多样性机制
  ├── 容易陷入局部最优
  └── 算子权重只按频率调整

  优化方案：
  ┌─────────────────────────────────────────────────────────┐
  │  1. 算子多样性奖励                                      │
  │     - 使用低频算子的因子获得奖励                        │
  │     - 使用高频算子的因子获得惩罚                        │
  │     - 鼓励探索新的算子组合                              │
  │                                                         │
  │  2. 结构多样性奖励                                      │
  │     - 树深度：中等深度(3-5)获得奖励                     │
  │     - 树宽度：中等宽度获得奖励                          │
  │     - 避免过于简单或过于复杂的结构                      │
  │                                                         │
  │  3. 机制族多样性奖励                                    │
  │     - 覆盖率低的机制族获得奖励                          │
  │     - 覆盖率高的机制族获得惩罚                          │
  │     - 鼓励探索新的机制族                                │
  │                                                         │
  │  4. 时间多样性奖励                                      │
  │     - 长期有效因子获得奖励                              │
  │     - 短期有效因子获得惩罚                              │
  │     - 鼓励发现长期稳定的因子                            │
  └─────────────────────────────────────────────────────────┘
```

### 验证结论（walk-forward OOS 实测，2026-09）

对已过硬闸门的 loopengine 因子做历史时点 T 的样本内计算，检验其与
T 之后（120/250 个交易日）样本外 IC 的关系（n=63~69）：

**结论 1：衰减检测有效。** 轻度/中度衰减组的 OOS IC 在 120 天窗口均接近零或为负
（mild -0.0006、moderate -0.0052），显著差于正常组（+0.0263）；重度组存在市场
状态切换时的集体误报（250 天窗口重度组 OOS +0.0707 明显恢复），故重度衰减采用
父本权重软惩罚（0.2）而非硬退役。

**结论 2：多目标评分原设计有害，已按数据重构。** 过闸因子间样本内夏普/索提诺/
卡玛/回撤与 OOS IC 显著负相关（ρ=-0.45~-0.60，p<0.001）——线性奖励平滑曲线
等于奖励过拟合。修正后：IC 主导（0.8），风险/夏普只保留灾难阈值惩罚（回撤>70%、
夏普<0.5 才扣分），120 天窗口 ρ 从旧版 -0.475 提升到 -0.087（中性），250 天窗口
+0.330（p=0.008）。IC 稳定性/趋势分量经验上反向预测 OOS（trend ρ=-0.47），
仅作诊断展示不计入评分。

**结论 3：过拟合是结构性现象。** 没有任何样本内单指标在两个窗口都正向预测 OOS IC
（ICIR 在 250 天窗口 ρ=+0.735，在 120 天窗口 ρ=-0.26）——单窗口排序指标不可靠，
多目标评分的价值在于风险筛查与诊断而非收益排序。
