# 因子 LLM 调用成本优化（2026-09-27）

## 生效行为

- 普通与事件定向挖掘均在规则、去重、冻结检查、统计闸门之后才做语义审查。审查只作标注，不修改统计通过结果。
- 每轮默认 LLM 生成 2 次、审查 1 次；事件轮传入共享轮内计数，避免绕过生成限制。
- QSYS 每天生成和审查分别最多 5 次非缓存请求，失败尝试也扣次数，预算使用 SQLite IMMEDIATE 事务防并发超额。
- 语义结果缓存 30 天；键包含规范表达式、使用字段语义、因子类型、审查版本、系统提示词、模型与采样参数。不缓存无效 verdict。程序搜索不受 LLM 次数限制。
- RD-Agent 每天默认 20 个远程聊天请求、60000 个预估输入加预留输出 tokens；单次输出最多 2048。每次重试/续写均重新申请额度。额度跨重启保留，午夜北京时间换日。
- RD-Agent 普通请求最多尝试 2 次。401/403 或明确模型权限拒绝即时熔断 24 小时，预算不足不重试。开启响应缓存读写；Flash 普通请求关闭额外推理。
- RD-Agent 新账本为 qsys/data/rdagent_llm_usage.db，LLM 用量页新增独立表格。历史调用未补录、分词估算不等于供应商账单。

## 配置

QSYS：LLM_LOOPENGINE_GENERATE_LIMIT=2、LLM_LOOPENGINE_REVIEW_LIMIT=1、LLM_GENERATE_DAILY_LIMIT=5、LLM_REVIEW_DAILY_LIMIT=5。
RD-Agent：RDAGENT_LLM_DAILY_CALL_LIMIT=20、RDAGENT_LLM_DAILY_TOKEN_LIMIT=60000、RDAGENT_LLM_USAGE_DB 可指定共享账本。
权限配置修复后可等待熔断到期；勿通过删除账本绕过预算。

## 限制

QSYS 与 RD-Agent 仍为分别记账与分别限额，不宣称统一金额硬上限。QSYS 新请求按保守文本输入估算加输出上限预留；接口返回的实际用量单独记录。失败且无 usage 的调用仍为未知，不是零消耗。升级前的历史输出预留不追溯重算。RD-Agent 新预算启用前的当日请求未扣入新账本。持续循环仍可能在本地重试运行，但熔断/限额拦截发生在网络请求之前。

## 验证

使用临时数据库及模拟模型响应验证：并发额度、缓存跨天复用/版本失效、无效结果不缓存、候选去重/冻结/统计失败不审查、预算耗尽回退程序搜索、权限错误只请求一次。未为测试发送真实模型请求。


## 问答预算与重试补充

- 单次输入上限 LLM_MAX_INPUT_TOKENS 默认 12000，采用本地 UTF-8 字节长度加消息开销的保守估算，不需要请求分词接口。
- LLM_DAILY_TOKEN_LIMIT 默认 30000 现在覆盖预估输入＋预留输出。失败调用额度不自动退还，缓存命中不占用。
- 每次尝试先在同一事务中扣额度并落 pending 明细，再调用模型。返回后更新 completed/empty/failed；每次重试单独申请额度和落记录。
- 关闭底层隐式重试。多轮问答仅在空正文且 length 时最多显式重试一次；单轮调用仅允许调用方明确指定的一次额外尝试。
- 重试预算不足立即停止，不覆盖首次用量；失败用量未返回记 NULL。前端展示“接口已报告 Token”，提示未知用量。
