# 2026-09-28 自动降仓启用

用户明确要求降仓自动执行、不再逐笔审核。本次在已有模拟柜台降仓功能上增加持久化自动授权和后台执行任务，不连接券商实盘账户。

## 行为

- `account_auto_reduce` 每 60 秒运行，使用独立的风险任务线程池；服务启动后注册，不依赖页面打开。
- 每轮确认自动模式、交易日历和连续交易时段，更新 T+1 可卖数量，按当前行情重新计算风险目标。风险刷新不调用 LLM。
- 风控未就绪或行情过期时保留原因，后续自动重试，不复用旧审批或盘前错误目标进行卖出。
- 基于最新账户状态重新生成自动方案；旧手工待审核方案不会直接被当成自动批准执行。
- 每次提交仍检查账户摘要、目标仓位、价格偏离、策略账本、可卖股数及交易条件；自动模式不绕过柜台限制。
- 进程间文件锁、SQLite 事务和方案幂等状态共同防止重入/重复下单。未完成委托存在时等待，已提交降仓卖单使用限定委托 ID 撮合，不顺带成交无关买单。
- 相同失败最多每 5 分钟重试。T+1/对账等阻塞状态在相关条件未变化时不重复创建方案，下一交易日可卖数量更新后自动重新计算。
- 暂停按钮会关闭自动模式，并撤销尚未成交的自动降仓卖单；已经成交的交易保留。手动委托不因此撤销。
- 页面启用自动模式后不显示审核勾选框，展示运行状态、逐笔成交与近期历史方案。只要行情和风险数据满足条件，无需用户逐笔操作。
