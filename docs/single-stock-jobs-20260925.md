# 单股手动表达式搜索与回测

入口：单股票历史数据 → 因子挖掘/因子回测。

- 手动提交持久化SQLite队列，独立single_stock_jobs工作进程执行；同一股票只允许一个排队/运行任务。页面每2秒刷新阶段、数量、失败原因和结果编号；完成后点击刷新结果。重启不丢排队任务，运行中断标记失败，不冒充完成、不自动重复提交。
- 单股日频表达式搜索：预设来源基础特征上生成加减乘除、滚动均值和差分组合，10～300个不同表达式，随机种子可复现，保留全部尝试。不是LLM生成、全市场准入或任意高频算法搜索。
- 日线至少180个日期，须通过数值/OHLC及可信日历完整性检查；分钟/盘口至少150日的当前版本可信归档，不用旧汇总或其他来源替代。后台不补行情、不自动删除数据。
- 50%训练/25%验证/25%最终留出，训练和验证末尾净化5日标签。训练至少40、验证至少30有效样本；探索门槛为训练绝对RankIC>=0.05，训练方向下验证RankIC>=0.02；按验证排序最多保存5个，允许0个。最终留出不参与搜索。重复搜索仍可能消耗留出独立性，未做多重搜索显著性认证。
- 保存表达式、依赖基础特征快照、来源版本、日历凭据摘要、输入哈希、参数、因子值和训练阈值。回测先从表达式复算核对保存值，缺停牌/涨跌停约束则失败；使用固定训练参数，5日信号、次日开盘模拟执行。
- 收益标签未复权，执行沿用现有日线账本限制，不宣称实盘高频成交回放。研究完成不自动给予原始数据清理许可。
