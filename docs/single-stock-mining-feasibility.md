# 单股真实挖掘入口评估（2026-09-25）

结论：可实现，但不能直接把单股按钮指向 LoopEngine.run_round。

已存在能力：loopengine/tree.py 表达式树与求值、genetics.py 随机生成/变异/交叉；mining_policy.py 跨进程互斥与输入指纹；engine.py 候选生成和评估。

接入障碍：engine._frames 依赖 all_pools、指定源股票面板；run_round 调用全池闸门并写全局因子注册表；树词汇未接 research_day_archive 字段；单股不适用横截面算子/样本门槛。当前 workbench.mine 仍为固定3候选研究。

建议独立任务：持久化 queued/running/completed/failed/cancelled 状态，参数保存股票、区间、来源、随机种子、候选预算；独立worker从已校验版本化特征构造单股时序帧；只允许因果时序及代数算子，禁止单股横截面rank；复用生成/变异/求值原语而非全局入库流程。

进度保存每个候选的表达式、依赖、失败原因、评估数量与耗时；固定训练/验证划分及标签净化，留出仅作独立最后评估；记录全部搜索尝试。候选数量可为零，不降低样本门槛。保存表达式、特征版本、因子值、参数、样本日期和输入指纹。登记入选因子后每天按固定版本计算信号，重新搜索创建新版本。

清理许可必须关联依赖清单和复算验收；不可仅以3个汇总特征完成即声称任意高频因子可复算。历史原始记录删除后仅支持已保存特征空间中的新表达式。未复权收益标签仍仅为诊断，正式评估需补复权与公司行为处理。

本轮修复：归档版本v2在必要旧特征实际写入成功后才发布ready；失败退避6小时，新日期优先；标签要求同花顺明确区间日历凭据并核对本地日期；新增全库归档覆盖，自动删除仍按股票授权。北交所无可信接口映射，保持阻断。没有在本轮接通真实挖掘按钮。
