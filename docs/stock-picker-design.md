# 选股神器设计方案：胜率驱动的因子组合

> 状态：方案待确认。目标：把"手动调权重"升级为"度量胜率 → 科学组合 → 样本外验证 → 固化执行"的完整链路。

## 〇、先讲清原理：组合为什么能提高胜率

单个因子的胜率（如 RankIC>0 的天数占比）通常在 52%~58%。组合能提高胜率有**且仅有**两个来源：

1. **分散化**：N 个互不相关的因子，各自胜率 55%，等权组合后胜率 ≈ 55% + 边际提升（IC 序列的波动被摊薄，ICIR 按 √有效因子数 增长）——**"有效"指低相关**。
2. **加权**：让历史胜率高、稳定性好（ICIR 高）的因子占更大权重。

反面教材：5 个相关性 0.9 的动量因子组合 ≈ 1 个因子，胜率不变还增加虚假信心。所以**相关性管理是组合的第一性问题**。

## 一、四层架构

```
① 度量层   每个因子/策略过滤器 → 一张"体检表"（胜率、ICIR、分层单调性、衰减）
② 组合层   相关性去冗余 → 多种加权方法（等权/ICIR/胜率投票/均值方差优化）
③ 验证层   滚动样本外（walk-forward）回测：组合 vs 等权 vs 基准，诚实胜率
④ 固化层   验证通过 → 存为"策略包" → 定时任务每日按包出名单（对接已有调度）
```

## 二、① 度量层：每个因子的"胜率体检表"

统一评估框架（point-in-time，杜绝未来函数）：

| 指标 | 定义 | 说明 |
|---|---|---|
| **IC 胜率** | RankIC > 0 的天数占比 | 因子层面最直观的"胜率" |
| IC 均值 / ICIR | mean/std of RankIC 序列 | 稳定性，加权的核心输入 |
| **Top组胜率** | 因子 Top10% 组合的 20 日超额 > 0 的调仓点占比 | 与"买因子最强的股票"体验一致 |
| 分层单调性 | 十分位组合收益是否单调 | 防止只有头部有效 |
| 衰减曲线 | forward 5/10/20/40 日 IC | 判断因子是短炒型还是长持型，决定调仓频率 |
| 相关矩阵 | 因子间 IC 序列相关性 | 去冗余依据 |

策略过滤器同样可度量：同一组合**开/关过滤器**的 A/B 胜率差（如"多头排列"开启后 Top-N 超额胜率 +3%）。

实现要点：进化因子在股票池上跑一次长窗口（~3年）拿到因子值时间序列 → 逐日 RankIC 序列落盘缓存（增量更新，每日 append 一天）。首次每因子约 10-30 秒，之后秒级。

## 三、② 组合层：从弱到强四档方法

| 方法 | 权重 | 适用 |
|---|---|---|
| 等权 | 1/N | 基线对照 |
| **ICIR 加权** | wᵢ ∝ ICIRᵢ | 稳健首选，业内标准做法 |
| 胜率投票 | wᵢ ∝ Top组胜率ᵢ | 直觉友好 |
| **均值-方差优化** | w* ∝ Σ⁻¹μ（因子 IC 序列的均值/协方差），简化版 wᵢ ∝ μᵢ/σᵢ² | 理论最优（假设 IC 平稳），需正则化防极端权重 |

前置步骤（关键）：**相关性去冗余**——按 ICIR 降序贪心选择，凡与已选因子 |ρ|>0.7 的剔除，页面给出剔除理由（"mom_5d 与 mom_20d 相关 0.83，已保留强者"）。

## 四、③ 验证层：诚实的胜率（方案的灵魂）

样本内胜率毫无价值——用全历史算权重再回测同一段历史，胜率必然虚高。必须：

- **Walk-forward 滚动样本外**：估计窗（过去 250 交易日算 IC/权重）→ 应用窗（随后 20 交易日实战）→ 滚动前移。**只有 OOS 胜率用于决策**。
- 报告双轨：IS 胜率（参考）vs OOS 胜率（决策），差距大 = 过拟合警报。
- 成本与可成交性：双边 ~0.16% 成本、剔除停牌、（数据局限：无 ST 标记，用文字说明）。
- **多重检验提示**：试了 50 个组合挑出最好的，其 OOS 胜率仍乐观——页面给出 deflated Sharpe 概念提示与"建议固定组合后观察 1 个月"的纪律建议。

预期管理：一个诚实的优秀组合，OOS Top组胜率从单因子 ~55% 提到 **60%~63%** 就是显著成果；宣称 70%+ 的基本都有未来函数。

## 五、④ 固化层：策略包

```
策略包 = {因子集 + 各因子权重/方向 + 过滤器集 + 股票池 + Top-N + 调仓周期}
```

- 一键保存验证通过的组合；策略包成为定时任务「板块扫描」的可选参数（每日自动出名单）
- 多策略包并存，跟踪各自近期命中表现（持续优胜劣汰）

## 六、与 RD-Agent 的边界（架构红线）

- QSYS 组合的是**已有因子的权重与过滤条件**——这是"配置"，不是因子生成，边界安全。
- 非线性组合（LightGBM/Logistic 对因子打分做 stacking）本质是"造新模型"——**不做在 QSYS 里**，这类需求应该提给 RD-Agent 的 `fin_quant`（模型进化闭环，本来就是它的活）。P4 可以考虑做"一键把策略包导出为 RD-Agent 的模型进化种子"。

## 七、页面设计（🪄 选股组合 tab 重构）

```
┌ ① 因子体检表（可排序表格：胜率/ICIR/Top组胜率/衰减/相关性）+ 衰减曲线图
├ ② 组合工作台：方法选择（等权/ICIR/胜率/均值方差）+ 相关性热图 + 去冗余建议
├ ③ 样本外验证：walk-forward 累计超额曲线 + IS/OOS 胜率对比 + 过拟合警报
└ ④ 策略包：保存/加载/对比 → 对接定时任务每日名单
```

## 八、分期实施

| 期 | 内容 | 体量 |
|---|---|---|
| S1 | 度量层：因子体检表 + RankIC 序列缓存管线（进化因子长窗执行 + 增量更新） | 中 |
| S2 | 组合层：四种加权方法 + 相关矩阵 + 去冗余 | 中 |
| S3 | 验证层：walk-forward OOS 面板 + IS/OOS 对比 + 成本 | 中大（核心） |
| S4 | 固化层：策略包存取 + 定时任务对接 + 过滤器 A/B 胜率 | 中 |

S1→S2 即可用，S3 是灵魂，S4 闭环到每日名单。
```

### 关键数字直觉

- 单因子典型：RankIC 胜率 52-58%，ICIR 0.2-0.5
- 5 个低相关（ρ<0.3）因子 ICIR 加权组合：ICIR 可翻倍，胜率 +5~8 个百分点
- 估计窗 250 日 + 应用窗 20 日是 A 股日频因子的实用起点
